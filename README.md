# GhOuL music — веб-версия

Новая реализация на HTML/CSS/JS без сборки и зависимостей. Работает как PWA: открой на телефоне и выбери «Добавить на главный экран».

## Запуск
```
python3 -m http.server 8080     # или любой статический сервер
```
Открой http://localhost:8080. Для установки как PWA нужен HTTPS (подойдёт GitHub Pages, Netlify, Cloudflare Pages).

## Что есть
- Аккаунт через Supabase: регистрация, вход, подтверждение почты, обновление токена.
- Поиск и подборки (iTunes Search API, фрагменты по 30 секунд), «Твоя волна» по лайкам и истории.
- Свои аудиофайлы: хранятся в IndexedDB на устройстве, играют целиком.
- Избранное и плейлисты, синхронизация через аккаунт.
- Текст песен (LRCLIB): для своих файлов строки подсвечиваются синхронно.
- 5 тем, подсветка под обложку, «спокойный режим» без анимаций, медиа-кнопки на экране блокировки.
- Статистика прослушивания (хранится только на устройстве).

## Что исправлено: «Слишком много попыток. Попробуй войти немного позже»
Эту ошибку возвращает Supabase (HTTP 429), когда исчерпан лимит писем подтверждения или запросов с одного IP.
В новой версии (`authError` в `app.js`):
- для регистрации и входа показываются разные тексты, а при лимите писем — отдельный;
- кнопка блокируется на время запроса (нет двойных отправок) и на время ожидания после 429 (по `Retry-After`, иначе `DEFAULT_COOLDOWN`/`EMAIL_COOLDOWN` из `config.js`);
- ожидание сохраняется при перезагрузке страницы.

Причину лучше убрать и на сервере (Supabase → Authentication):
1. SMTP Settings → подключить свой SMTP (Resend, Brevo и т. п.): встроенная почта даёт лишь несколько писем в час на весь проект.
2. Rate Limits → поднять лимиты писем и регистраций.
3. На время разработки можно отключить Confirm email.

## Таблица для синхронизации (выполнить в SQL Editor Supabase)
```sql
create table if not exists public.ghoul_library (
  user_id uuid primary key references auth.users on delete cascade,
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);
alter table public.ghoul_library enable row level security;
create policy "own row" on public.ghoul_library
  for all using (auth.uid() = user_id) with check (auth.uid() = user_id);
```
Если таблицы нет, приложение просто покажет «Синхронизация недоступна» и продолжит хранить всё локально.

## Ограничения
- В старом приложении был собственный бэкенд «Catalog» (SoundCloud, YouTube, радио, подписки, профили). В APK его нет, поэтому здесь поиск идёт через открытый iTunes API (только 30-секундные фрагменты). Полноценные источники подключаются в функциях `itunes()` / `playIndex()`.
- Визуализатор на экране плеера декоративный.
